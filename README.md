# Readarap Lyric Flip Lab

Bilingual React demo for the Name Flo / Freestyle Karaoke protocol using Kendrick Lamar & SZA's "luther".

## Features
- Pre-loaded Chorus and Verse 1 examples (English + Spanish)
- User swap input with live syllable counting
- Scoring sliders for Syllable / Rhyme / Cadence / Energy
- Readarap tier + RapCoins output

## Run Locally
```bash
npm install
npm run dev
```

## Deploy
Connect to Vercel for one-click deploy.
